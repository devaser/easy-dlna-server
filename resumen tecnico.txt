Resumen técnico: Easy DLNA Server
1. Objetivo

Servidor multimedia DLNA/UPnP ligero, de código abierto. Comparte carpetas de vídeo en la red local con TV y reproductores. Soporta subtítulos SRT externos, marcadores de reproducción, SSDP, un servidor HTTP con rangos y una biblioteca SQLite.

Licencia: GPL-3.0-or-later. Copyright: Copyright (C) 2026 devaser (https://github.com/devaser).
Publicación: repositorio previsto https://github.com/devaser/EasyDLNAServer, aún sin crear. Antes se llamaba “SMSNG DLNA Server” y se renombró por motivos legales.
Idioma: todo el proyecto va en inglés (código, comentarios, instalador, README y ejemplos, por ejemplo ~/Videos sin tilde). Con el usuario se habla en español.
2. Arquitectura y stack
Lenguaje y dependencias: Python 3.13 en Windows, 3.12 probado en Ubuntu, mínimo 3.9. aiohttp para todos los sistemas. pywin32, pystray y Pillow solo en Windows. pyinstaller solo para compilar. Los requirements.txt usan marcadores sys_platform.
Base de datos: SQLite en modo WAL (library.db), esquema en database/schema.sql.
Datos (platform_paths.get_data_dir()):
Windows: %ProgramData%\Easy DLNA Server.
Linux como usuario: ~/.local/share/easydlna.
Linux como sistema (root o usuario easydlna): /var/lib/easydlna.
macOS: ~/Library/Application Support/Easy DLNA Server (o /Library/... como sistema).
Se puede sobrescribir con EASYDLNA_DATA_DIR.
Dentro: config/shared_folders.json (lista de rutas), config/settings.json ({"http_port": N}), config/device_uuid.txt (UUID único por instalación), database/library.db, logs/ y, en Linux/macOS, scan.lock.
Estructura (los ficheros me llegan planos y el usuario los coloca):
Raíz: main.py, service.py (solo Windows), tray.py (solo Windows), shared_folders.py (Settings con tkinter), scan_library.py, scan_lock.py, power.py, platform_paths.py, app_settings.py, windows_firewall.py, easydlna.py (CLI), EasyDLNASetup.iss, README.md, THIRD_PARTY_NOTICES.md, requirements*.txt, .gitignore, .gitattributes, LICENSE y los EasyDLNA*.spec.
database/: db.py, schema.sql.
media/: scanner.py, subtitles.py.
server/: http_server.py, didl.py, upnp.py, ssdp.py, device.py.
Herramientas de un solo uso, no se suben al repositorio: rename_project.py, find_spanish.py.
Ficheros que no he visto: schema.sql, subtitles.py y los .spec.
Lógica clave
main.py: arranca la base de datos y escanea, solo si hay carpetas válidas. Si no hay carpetas o el escaneo falla, el servidor sigue. Luego inicia power, el servidor HTTP y SSDP, y espera al evento de parada.
ssdp.py: no necesita red al arrancar. Una tarea revisa las interfaces cada 10 s. En Linux las enumera por ioctl y descarta docker, veth, br-, virbr, tun, tailscale y wg. Se une y deja el grupo multicast por interfaz y manda NOTIFY al cambiar y cada 900 s. En macOS usa SO_REUSEPORT.
upnp.py y http_server.py: las URL usan el host de la petición (request.url.host) y el puerto configurado. stream_file(keep_awake=True) avisa a power.
device.py: UUID persistente. Si no puede guardarlo, deriva uno estable del nombre del equipo.
power.py: en Windows usa PowerCreateRequest con el motivo “Easy DLNA Server is streaming media” (respaldo SetThreadExecutionState). En Linux usa systemd-inhibit y en macOS caffeinate. Gracia de 300 s tras la última transmisión.
scan_lock.py: mutex Local\EasyDLNA_LibraryScan en Windows y flock en POSIX. Un segundo escaneo sale con código 3 y el tray y Settings lo muestran como “already running”.
scanner.py: distingue mayúsculas solo en Linux e ignora los ficheros ._*.
tray.py: controla el servicio con win32service. Al salir cierra Settings (primero con taskkill suave, luego forzado) y mata el árbol del escáner.
shared_folders.py: carpetas, campo “HTTP port” (1024-65535) y, al guardar, lanza el escáner en segundo plano (salida a scan.log). En Windows reinicia el servicio con cmd /c net stop EasyDLNAServer & net start EasyDLNAServer. Los usuarios pueden arrancar y parar el servicio por el SDDL.
service.py: servicio pywin32 EasyDLNAServer. Al arrancar llama a sync_http_rule(get_http_port()).
easydlna.py: comandos run, setup, install-service [--user|--system] [--firewall] [--no-start] [--dry-run], uninstall-service, start|stop|restart|enable|disable, status, logs [-f], folders list|add|remove [--no-scan], scan, port [N] [--reset] [--no-restart] [--force] y firewall open|close [--port] [--dry-run].
Unidades systemd: usuario (WantedBy=default.target) o sistema (User=easydlna, StateDirectory=easydlna, endurecimiento). Llevan Restart=on-failure, RestartPreventExitStatus=78, StartLimitBurst=5 y StartLimitIntervalSec=60.
Puerto ocupado: run sale con el código 78 y un mensaje claro.
Modo sistema: los comandos que escriben requieren sudo y bajan privilegios al usuario easydlna. port exige root y hace chown de settings.json.
Mensajes: invocation() muestra la ruta absoluta del comando bajo sudo.
Cortafuegos: reglas ufw para las redes privadas 10/8, 172.16/12 y 192.168/16, con el comentario “Easy DLNA Server”.
Instalador Windows (EasyDLNASetup.iss, Inno Setup 6.3 o posterior, solo inglés, AppId={B1F4C7A2-5D3E-4A89-8E26-9C0D7F3A1B64}, versión 0.3.2):
Antes de copiar: cierra el tray, Settings y Scanner con taskkill. Si el servicio existe, lo para y espera a que desaparezca su proceso (lo mata a los 60 s) y lo elimina.
Después de copiar: instala el servicio con --startup auto install (con alternativas), sc config start= delayed-auto, sidtype unrestricted y sdset con permiso para usuarios interactivos.
Firewall: tarea opcional marcada por defecto. Crea EasyDLNA_SSDP (UDP 1900) y EasyDLNA_HTTP (TCP 8200) con program, service, remoteip=localsubnet y perfiles private, domain y public.
Directorios y accesos: [Dirs] con permiso de modificación para usuarios en {commonappdata}\Easy DLNA Server, que no se borra al desinstalar. Acceso directo del tray en el inicio de todos los usuarios.
Silencioso: /VERYSILENT /TASKS="!firewall".
Compilación Windows: un .spec por ejecutable, con py -3.13 -m PyInstaller --noconfirm --clean EasyDLNA<X>.spec, y después ISCC.exe EasyDLNASetup.iss. Genera dist\EasyDLNA{Service,Tray,Scanner,Settings}.exe.
